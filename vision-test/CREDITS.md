# DND NPC Owlbear extension

The code is the dnd-npc project's own, and so are the icons and the effect shaders, apart from two libraries:
`obr-sdk.js` is the Owlbear Rodeo SDK (MIT License, Owlbear Rodeo).
`fog/clipper.js` is clipper-lib 6.4.2, Angus Johnson's Clipper polygon clipping library in JavaScript
(Boost Software License 1.0, http://www.boost.org/LICENSE_1_0.txt), unchanged apart from a comment header
and the two lines that make it an ES module.
No game text is published here: spell lists and the party reach the players live from the DM's panel.
